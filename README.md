School Record Management Database

A MySQL-based school record management database designed to manage students, staff, academic records, attendance, examinations, guardians, and school fee payments.

Features

Student enrollment and record management

Staff and teacher records

Classes and academic year management

Subjects and teacher assignments

Student guardian information

Attendance tracking

Examination and grading management

School fee structures and payment tracking

Stored procedures for common database operations

SQL views for reporting and data analysis

Database Structure

The database is organized into several areas:

Identity & Address — Countries, regions, cities, addresses, and personal information

Academic Structure — Academic years, terms, classes, students, and staff

Subjects & Teaching — Subjects, categories, classes, and teacher assignments

Guardians — Student and guardian relationships

Attendance — Student attendance records and statuses

Examinations — Exams, grading systems, and student results

Finance — Fee structures, payment methods, and student payments

SQL Files

newschooldb.sql — Creates the database schema, tables, relationships, primary keys, and foreign keys.

storedprocedures and views.sql — Contains stored procedures and views used for database operations and reporting.

newdbtestings.sql — Contains sample data and queries used to test the database.

Technologies
-MySQL
-SQL

Purpose

This project was created to practice relational database design and SQL concepts including table relationships, foreign keys, joins, stored procedures, views, aggregation, and database queries.
